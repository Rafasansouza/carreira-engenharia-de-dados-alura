## 🔹 O que é Big Data?

Big Data se refere ao grande volume de dados gerados em alta velocidade e com grande variedade de formatos — estruturados, semi-estruturados e não estruturados. :contentReference[oaicite:2]{index=2}

---

## 🔹 O que é Engenharia de Dados?

Engenharia de Dados é a área responsável por desenvolver, implementar e manter o ambiente que possibilita o processamento e entrega de dados de qualidade, desde a origem até o destino. :contentReference[oaicite:3]{index=3}

Esse ambiente normalmente é chamado de **pipeline de dados**, composto por etapas como extração, transformação e carregamento dos dados. :contentReference[oaicite:4]{index=4}

---

## 📊 Pipeline de Dados

Um pipeline é o processo pelo qual os dados são movimentados da origem para o destino, passando por:

1. Fontes de dados (bancos, APIs, sistemas, etc.)
2. Processamento dos dados (transformação, filtragem, agregação)
3. Destino dos dados (como Data Lakes ou Data Warehouses) :contentReference[oaicite:5]{index=5}

---

## 👩‍💻 O que faz uma pessoa Engenheira de Dados?

Uma pessoa Engenheira de Dados é responsável por:

- Integrar, limpar, estruturar e disponibilizar dados.  
- Montar e manter pipelines de dados.  
- Tornar dados acessíveis para outros profissionais de dados.  
- Incentivar a cultura data-driven nas organizações. :contentReference[oaicite:6]{index=6}

---

## 🚀 Importância da Engenharia de Dados

Engenharia de Dados é crucial para qualquer organização que dependa de dados para tomada de decisão, especialmente em ambientes de Big Data, permitindo que dados de qualidade sejam usados para análises e insights. :contentReference[oaicite:7]{index=7}
